# CodeAlpha Hangman Game

## About the Project

This is a simple text-based Hangman game created using Python as part of the CodeAlpha Python Programming Internship.

## Features

* Uses 5 predefined words
* Randomly selects a word
* Player guesses one letter at a time
* Allows 6 incorrect guesses
* Runs in the console

## Technologies Used

* Python
* Random module

## How to Run

1. Download the Python file.
2. Open it using Python or a code editor.
3. Run the program.
4. Enter one letter at a time to guess the word.
